# Exercícios de LP2 em Java

Projeto de estudo de Linguagem de Programação II da FATEC. O código-fonte fica em `src/edu/fatec/lp2` e cada pacote tem seu próprio `Main.java`.

| Pacote | Exercício | Conceitos praticados |
| --- | --- | --- |
| `exercicio1` | WhatsApp | Classe abstrata, herança, polimorfismo e arrays |
| `exercicio2` | Supermercado | Interface `Calculavel`, descontos e total da lista de compras |
| `exercicio3` | Cadastro de turma | Enum de cursos, `ArrayList`, limite de vagas e matrícula única |

## Como executar

Abra a pasta no IntelliJ IDEA, configure um JDK e marque `src` como **Sources Root** se necessário. Abra o `Main.java` do exercício desejado e execute o método `main`.

O cadastro de turma demonstra a inclusão de alunos. As operações de consulta, alteração e exclusão do enunciado ficam como exercícios de prática.
